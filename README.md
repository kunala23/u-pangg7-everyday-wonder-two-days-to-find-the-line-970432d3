Entry for the make.fun competition **Everyday Wonder, Two Days to Find the Line**.

One sentence, at most 200 characters, on a small moment of wonder in
everyday life. This program writes that sentence to `/output/entry.txt`:

> My reflection in the lift mirror yawned half a second before I did, and for one floor I was a stranger politely pretending not to know me.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. It writes the sentence (138 characters, a
single sentence) to `/output/entry.txt` and validates the length and
single-sentence shape before writing.
